# PharmacySystem
# Программный комплекс для автоматизации формирования заявок на лекарственные средства

Система предназначена для оптимизации процесса лекарственного обеспечения в многопрофильных стационарах. Комплекс автоматизирует ключевые бизнес-процессы больничной аптеки, позволяя формировать заявки на приобретение лекарственных средств как в ручном, так и в автоматическом режиме на основе математической модели расчета потребности.

## Основные функции

*   **Авторизация и разграничение доступа:** Вход в систему для ролей «Фармацевт» и «Администратор».
*   **Мониторинг запасов:** Отслеживание текущих остатков, расхода и минимального неснижаемого запаса лекарственных средств.
*   **Формирование заявок:**
    *   *Ручной режим:* Создание заявок на основе выбранных препаратов.
    *   *Автоматический режим:* Генерация заявок на основе встроенной математической модели, учитывающей недельный расход и приоритетность.
*   **Учет движений:** Фиксация всех операций поступления и расхода препаратов.
*   **Администрирование:** Управление пользователями, справочниками и настройками системы.
*   **Генерация отчетов:** Формирование отчетной документации по запасам и заявкам.
